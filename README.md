# Matchup Rotazioni

App web installabile per il matchup delle partenze di rotazione nella pallavolo, a partire dai file DataVolley (.dvw).

- **Panchina**: partenza consigliata, previsione della partenza avversaria, piano di battuta, distribuzione dell'alzata, incroci a rete.
- **Studio**: pattern del coach avversario, matrice 6×6 delle partenze, statistiche per rotazione e per giocatrice.
- **Dati**: caricamento dei file .dvw. I file restano solo sul dispositivo (memoria del browser): nessun dato viene inviato o pubblicato.

Versione inglese: `en.html`. Funziona offline dopo la prima apertura.

## Setter Radar

Seconda app nella cartella `setter-radar/`: rilevazione da panchina della distribuzione della palleggiatrice avversaria (ricezione per zona, riquadri per chiamata del centrale, traiettorie, segnale per corsia di battuta, report pre-gara dai file .dvw). Installabile e offline come Matchup Rotazioni; i dati restano solo sul dispositivo.
